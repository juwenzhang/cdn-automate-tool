* [cdn-automate-tool](https://github.com/juwenzhang/cdn-automate-tool)

* 实现的功能点有：

    * 1. 控制 HTML 模板中 CDN 链接生产阶段自动注入 HTML 文档中 cheerio 

    * 2. CDN 链接的网络加载的异常处理，onerror 和 onload 等事件的处理

    * 3. prefetch preload dns-prefetch 等预加载和预请求优化

    * 4. defer async 控制 js 脚本的执行时机

    * 5. 支持 webpack 和 vite 插件的配置
